# AURAMODE

Modern E-Commerce Web Application built with **.NET 8 (ASP.NET Core)** and modern HTML5/CSS3 frontend.

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/aliyabubakarr-creator/auramode)

## Features
- **Frontend:** Responsive shopping catalog, product details, cart, checkout, and customer account portals.
- **Backend:** ASP.NET Core 8 REST APIs with Entity Framework Core & SQLite database.
- **Payment Integration:** Ready for Paystack checkout flow.
- **Containerized:** Multi-stage Docker setup ready for free cloud deployment.

## Deploying to Render
Click the **Deploy to Render** button above, or visit:

## Quick Start (Local)
```bash
dotnet restore
dotnet run
```
Access locally at `http://localhost:5000`.
